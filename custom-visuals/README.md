# Custom Visuals

This project uses an HTML custom visual to render DAX-generated HTML/CSS inside Power BI.

Current visual file:

`../STANDALONEhtmlContent443BE3AD55E043BF878BED274D3A6855.1.6.0.0.pbiviz`

## How To Use

1. Open Power BI Desktop.
2. Go to the visualizations pane.
3. Select "Import a visual from a file".
4. Choose the `.pbiviz` file.
5. Add the visual to the report canvas.
6. Bind the desired HTML measure to the visual.

## Implementation Notes

- Page content is generated by DAX measures that return HTML strings.
- Native Power BI buttons are used for page navigation.
- The custom visual is responsible only for rendering the HTML layout.
